# Proximity-Search-Google-Map
A map I built for a client that allows users to perform a proximity search to locate the nearest partners.

Live Demo Here
https://www.bobbydudek.com/project/rail-events-inc-proximity-search-google-map/

(Project history and context)
I originally developed this for a client who was on a Drupal website. They had between 50 and 100 partners listed on their website that integrated with a map module, which was searchable with a built-in geocoder. Eventually, that module reached EOL, became deprecated, and then stopped functioning altogether. The client was set on a new map that would function exactly the same way. I later implemented the same map on their WordPress site. So I ended up developing 2 other versions that were more polished but for demo purposes, this is the bare bones standalone version that's a great foundation for many projects. 

Inside index.html, make sure to replace XXXXXXXXXXXXXXXXXXXX with your Google Maps JavaScript API key (with the geocoding API enabled) and your Google reCAPTCHA API keys (V2 invisible).
